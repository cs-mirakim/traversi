# Antigravity Prompts - Copy Paste

## Prompt 1 - Init Project
"Create a Next.js 14 app router project with Tailwind, TypeScript. App page has a hero 'RM Berapa Boleh Pergi Mana?' with budget slider RM1000-5000 and 3 vibe buttons Beach/City/Nature. No map. Use Supabase client placeholder."

## Prompt 2 - API Recommend
"Create /api/recommend route.ts that receives {budget, days, vibe}. It has mock data 10 destinations (Krabi, Bali, Dalat, etc) with flight, hotel, food cost in RM. Filter where total <= budget, return top 3. Add Supabase cache check."

## Prompt 3 - Destination Card
"Create DestinationCard component that shows city, country, total RM, breakdown bar (flight hotel food), badges Visa Free and Halal Mudah/Susah, and 1 sentence why fits budget. Style like AirAsia Move card, clean, no map."

## Prompt 4 - Gemini Integration
"Create lib/gemini.ts that uses Gemini 1.5 Flash to estimate hotel per night and food per day for a given city for Malaysian backpacker budget, return JSON {hotel, food, transport}. Also function to generate 1 sentence reason."
