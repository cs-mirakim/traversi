# Traversi - Travel Versi Anda

Sistem kalkulator bajet terbalik pertama untuk belia Malaysia. Masukkan bajet RM, sistem bagi 3 destinasi yang muat bajet siap pecahan flight, hotel, makan, transport + semak visa passport MY + skor halal.

Tagline: Travel Versi Anda / Your Trip, Your Version

## Stack Free 100%
- Next.js 14 App Router + Tailwind + shadcn
- Supabase (Postgres cloud) + Vercel (hosting) = Cloud infra
- Gemini 1.5 Flash (AI Studio free) = AI
- Amadeus Test 2000 calls/month + REST Countries + ExchangeRate + Overpass API

## Quick Start
1. Copy `.env.example` to `.env.local` isi keys (semua free no credit card)
2. `npm install`
3. `npm run dev` -> localhost:3000
4. Landing pitch deck di `/`, kalkulator di `/kalkulator`
