# PRD - Travel DIY RM

## Problem
Student Malaysia ada RM2000-RM3000 nak travel tapi tak tahu boleh pergi mana. Skyscanner tunjuk flight je, tak tunjuk total kos + halal + visa untuk passport Malaysia.

## Solution
Web app simple: Input RM + berapa hari + dari KL -> Output 3 destinasi yang muat budget siap pecahan.

## Target User
Student / fresh grad Malaysia, bajet RM1500-RM4000, concern halal & visa free.

## MVP Features (Hackathon)
1. **Input Form**
   - Budget (RM) - slider 1000-5000
   - Duration (3-7 hari)
   - Dari (default KLIA)
   - Vibe: Beach / City / Nature / Shopping
   - Pax (1-4)

2. **Recommendation Engine**
   - Hit Supabase cache dulu
   - Kalau takde: Amadeus flight price KL->dest + Gemini estimate hotel/food/transport per day
   - Filter: total <= budget
   - Sort by best value

3. **Destinasi Card (3 cards)**
   - Negara + city (contoh: Krabi, Thailand)
   - Total: RM2350 / RM2500 (95%)
   - Breakdown: ✈️ RM600 + 🏨 RM800 (4 malam) + 🍛 RM500 + 🚕 RM200
   - Badge: Visa Free 30 hari | Halal: Senang (320 kedai halal) | Currency: 1 THB = RM0.13
   - 1 ayat Gemini: "Kenapa ngam dengan bajet kau"

4. **Detail Drawer (optional)**
   - Click card -> itinerary ringkas 4 hari generated by Gemini

## Out of Scope for MVP
- Booking / payment (just estimate)
- Real-time hotel API berbayar
- Map besar (no map)

## Success Metric
Judge boleh masuk RM2000, dapat 3 cadangan dalam <5 saat.
