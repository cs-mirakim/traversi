# Travel DIY RM - Bajet Berapa Boleh Pergi Mana?

> Idea: User masuk budget RM + hari, system recommend 3 negara yang lepas + breakdown flight/hotel/makan dalam RM + halal check.

**Stack FREE 100%:** Next.js 14 + Supabase + Gemini 1.5 Flash + Amadeus Test + REST Countries + ExchangeRate

**MVP 1 Day:** 1 input -> 3 cards destinasi. No map.

## Quick Start
1. `cp .env.example .env.local` isi keys
2. `npm install`
3. `npm run dev`
